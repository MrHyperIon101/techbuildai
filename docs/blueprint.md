# **App Name**: TechBuild AI

## Core Features:

- AI PC Builder: AI-powered PC build tool using real-time data from the web to recommend the best components within the user's budget. The tool will incorporate an LLM that determines which information to present to the user based on the request and on available components.
- Component Details: AI-driven component detail retriever providing helpful details about PC components using real-time data. The tool will incorporate an LLM that determines which information to present to the user based on the request.
- Conversation History: Conversational history to maintain context during the PC build process.
- Bottleneck Calculator: Bottleneck calculator that provides a percentage indicating potential bottlenecks in the PC build.
- PC Build Guide: Step-by-step PC build guide with visual aids and instructions.
- UI Design: Bento-styled pill-shaped UI elements with glassmorphism effects.
- Navigation: Centered pill-shaped navigation bar for intuitive navigation.

## Style Guidelines:

- Primary color: Light Purple (#B09FDA) for a modern, cool, and sophisticated tech vibe.
- Background color: Pure solid black (#000000) for a dark mode interface.
- Accent color: Electric Blue (#7DF9FF) for highlighting key elements and CTAs, ensuring high contrast and visual appeal.
- Body and headline font: 'Inter', a grotesque-style sans-serif, offering a modern, machined look.
- Code font: 'Source Code Pro' for displaying code snippets.
- Use of Bento-style pill-shaped UI with glassmorphism effects to create a modern and visually appealing layout.
- Smooth and subtle animations across the UI to enhance user experience and provide visual feedback.
